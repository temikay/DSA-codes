Simulation package: complementarity-aware skill-partner recommendation
Order: final_matrix.py (re-index matrix to final S0-S19 order) -> fw2.py (framework) -> run_all.py / run_graph.py -> make_figs.py
Requires: numpy pandas scipy networkx matplotlib. Seeds are fixed in the scripts.
results/M_final_order.csv is the synergy matrix in the final skill order.
matrix.py holds the matrix as labelled in the original table; final_matrix.py maps it by skill name.
